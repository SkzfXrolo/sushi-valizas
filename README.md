# Sushi Valizas

Sitio base de **Sushi Valizas** (By Valizas Hostel).

## Stack

- Vite + HTML/CSS/JS
- i18n: ES / EN / PT
- Tema claro / oscuro
- Deploy: Vercel

## Config pendiente

Editá `src/config.js` cuando tengas:

- Número WhatsApp Business
- URL del catálogo WhatsApp (`waCatalog`)

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
